## **1. 함수(Function)**

함수(Function)는 입력된 값에 대해 연산을 수행한 후 그 결과를 반환하는 일련의 코드 집합이다.

내장 함수(Built-in Function)는 크게 **단일행 함수(Single-Row Function)**와 **다중행 함수(Multi-Row Function)**로 구분된다.

| 구분                          | 설명                                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 단일행 함수(Single-Row Function) | 하나의 행에 대해 연산을 수행한 후 결과를 반환한다. 1:M 조인에서도 M쪽의 각각의 행에 대해 적용된다.                                                  |
| 다중행 함수(Multi-Row Function)  | 여러 행을 대상으로 연산하여 하나의 결과를 반환한다. 집계 함수(COUNT, SUM, AVG), 그룹 함수(ROLLUP, CUBE), 윈도우 함수(RANK, ROW_NUMBER) 등이 해당한다. |

#### **단일행 함수의 특징**

* SELECT절, WHERE절, ORDER BY절에서 사용할 수 있다.
* 각 행마다 한 번씩 적용되어 **행마다 하나의 결과**를 반환한다.
* 함수를 **중첩**해서 사용할 수 있다. (안쪽 함수부터 실행)
* 종류: 문자 함수, 숫자 함수, 날짜 함수, 변환 함수, NULL 관련 함수, CASE

---

## **2. 문자 함수(Character Function)**

문자 함수는 문자열을 대상으로 다양한 연산을 수행하는 함수이다.

---

### **2.1 LOWER**

입력된 문자열을 모두 소문자로 변환하여 반환한다.

#### **문법**

```sql
LOWER(arg)
```

* **arg** : 문자열 값 또는 문자열형 칼럼

#### **예제**

```sql
SELECT LOWER(NAME) AS NAME
FROM MEMBER;
```

---

### **2.2 UPPER**

입력된 문자열을 모두 대문자로 변환하여 반환한다.

#### **문법**

```sql
UPPER(arg)
```

* **arg** : 문자열 값 또는 문자열형 칼럼

#### **예제**

```sql
SELECT UPPER(NAME) AS NAME
FROM MEMBER;
```

---

### **2.3 CHR**

입력된 ASCII 코드값에 해당하는 문자를 반환한다.

#### **문법**

```sql
CHR(arg)
```

* **arg** : ASCII 코드값

> SQL Server에서는 `CHR` 대신 `CHAR` 함수를 사용한다.

#### **예제**

```sql
SELECT CHR(97)
FROM DUAL;
```

#### **해설**

1. ASCII 코드 97에 해당하는 문자 `'a'`를 반환한다.

---

### **2.4 TRIM**

문자열의 양쪽 끝에서 공백 또는 지정한 문자를 제거하여 반환한다.

#### **문법**

```sql
TRIM([[LEADING | TRAILING | BOTH] 문자 FROM] 문자열)
```

| 인자       | 설명            |
| -------- | ------------- |
| LEADING  | 문자열의 왼쪽에서 제거  |
| TRAILING | 문자열의 오른쪽에서 제거 |
| BOTH     | 양쪽에서 제거(기본값)  |

문자를 지정하지 않으면 공백을 제거한다.

> TRIM에서 제거할 문자는 **한 글자만** 지정할 수 있다.

#### **예제 ① : 공백 제거**

```sql
SELECT TRIM('  GOOD ')
FROM DUAL;
```

#### **해설**

1. 문자열의 앞뒤 공백을 제거하여 `'GOOD'`을 반환한다.

---

#### **예제 ② : 왼쪽 문자 제거**

```sql
SELECT TRIM(LEADING '가' FROM '가나다라')
FROM DUAL;
```

#### **해설**

1. 문자열의 왼쪽에서 `'가'`를 제거하여 `'나다라'`를 반환한다.

---

#### **예제 ③ : 오른쪽 문자 제거**

```sql
SELECT TRIM(TRAILING '가' FROM '가나다라가')
FROM DUAL;
```

#### **해설**

1. 문자열의 오른쪽에서 `'가'`를 제거하여 `'가나다라'`를 반환한다.

---

#### **예제 ④ : 양쪽 문자 제거**

```sql
SELECT TRIM(BOTH '가' FROM '가나다라가')
FROM DUAL;
```

#### **해설**

1. 문자열의 양쪽에서 `'가'`를 제거하여 `'나다라'`를 반환한다.

---

### **2.5 LTRIM**

문자열의 왼쪽 끝에서 공백 또는 지정한 문자를 제거하여 반환한다.

#### **문법**

```sql
LTRIM(arg1 [, arg2])
```

* **arg1** : 문자열 값 또는 문자열형 칼럼
* **arg2** : 제거할 문자 또는 문자열(생략 시 공백 제거)

> SQL Server에서는 `arg2`를 사용할 수 없으며 공백만 제거할 수 있다.

> **주의:** Oracle에서 `arg2`는 하나의 문자열이 아니라 **문자의 집합**으로 동작한다. 왼쪽에서부터 `arg2`에 포함된 문자가 나오는 동안 계속 제거한다.

#### **예제 ①**

```sql
SELECT LTRIM('가나다라', '가')
FROM DUAL;
```

#### **해설**

1. `'가나다라'`의 왼쪽에서 `'가'`를 제거하여 `'나다라'`를 반환한다.

#### **예제 ② : 문자 집합**

```sql
SELECT LTRIM('가나다라', '나가')
FROM DUAL;
```

#### **해설**

1. 왼쪽부터 `'가'`, `'나'`가 모두 집합에 포함되므로 제거하고, `'다'`에서 멈춰 `'다라'`를 반환한다. (집합 안의 순서는 상관없다.)

---

### **2.6 RTRIM**

문자열의 오른쪽 끝에서 공백 또는 지정한 문자를 제거하여 반환한다.

#### **문법**

```sql
RTRIM(arg1 [, arg2])
```

* **arg1** : 문자열 값 또는 문자열형 칼럼
* **arg2** : 제거할 문자 또는 문자열(생략 시 공백 제거)

> SQL Server에서는 `arg2`를 사용할 수 없으며 공백만 제거할 수 있다.

> LTRIM과 마찬가지로 `arg2`는 **문자의 집합**으로 동작한다.

#### **예제**

```sql
SELECT RTRIM('가나다라', '라')
FROM DUAL;
```

#### **해설**

1. `'가나다라'`의 오른쪽에서 `'라'`를 제거하여 `'가나다'`를 반환한다.

---

### **2.7 SUBSTR**

문자열에서 원하는 부분 문자열을 추출하여 반환한다.

#### **문법**

```sql
SUBSTR(arg1, arg2 [, arg3])
```

| 인자   | 설명                      |
| ---- | ----------------------- |
| arg1 | 문자열 또는 문자열형 칼럼          |
| arg2 | 추출을 시작할 위치(1부터 시작)      |
| arg3 | 추출할 길이(생략 시 문자열 끝까지 추출) |

> SQL Server에서는 `SUBSTR` 대신 `SUBSTRING`을 사용하며, 길이(arg3)를 생략할 수 없다.

> Oracle에서는 시작 위치(arg2)에 **음수**를 쓰면 문자열 끝에서부터 센다. 예: `SUBSTR('GOOD MORNING', -3)` → `'ING'`

#### **예제**

```sql
SELECT SUBSTR('GOOD MORNING', 1, 4)
FROM DUAL;
```

#### **해설**

1. `'GOOD MORNING'`의 첫 번째 문자부터 4개의 문자를 추출하여 `'GOOD'`을 반환한다.

---

### **2.8 LENGTH**

문자열의 길이를 반환한다.

#### **문법**

```sql
LENGTH(arg)
```

* **arg** : 문자열 값 또는 문자열형 칼럼

> SQL Server에서는 `LENGTH` 대신 `LEN` 함수를 사용한다.

#### **예제**

```sql
SELECT LENGTH('GOOD MORNING')
FROM DUAL;
```

#### **실행 결과**

```
12
```

> 문자열 사이의 공백도 하나의 문자로 계산된다.

---

### **2.9 REPLACE**

문자열에서 특정 문자열을 다른 문자열로 변경하여 반환한다.

#### **문법**

```sql
REPLACE(arg1, arg2 [, arg3])
```

| 인자   | 설명               |
| ---- | ---------------- |
| arg1 | 문자열 또는 문자열형 칼럼   |
| arg2 | 변경할 대상 문자열       |
| arg3 | 변경될 문자열(생략 시 삭제) |

#### **예제 ① : 문자열 변경**

```sql
SELECT REPLACE('Good Morning', 'Morning', 'Afternoon')
FROM DUAL;
```

#### **해설**

1. `'Morning'`을 `'Afternoon'`으로 변경하여 `'Good Afternoon'`을 반환한다.

---

#### **예제 ② : 문자열 삭제**

```sql
SELECT REPLACE('Good Morning', 'Good ')
FROM DUAL;
```

#### **해설**

1. `'Good '`을 삭제하여 `'Morning'`을 반환한다.

---

### **2.10 ASCII**

입력된 문자의 ASCII 코드값을 반환한다. CHR의 반대 기능이다.

#### **문법**

```sql
ASCII(arg)
```

#### **예제**

```sql
SELECT ASCII('a')
FROM DUAL;
```

#### **해설**

1. 문자 `'a'`의 ASCII 코드값 `97`을 반환한다.

---

### **2.11 CONCAT**

두 문자열을 연결하여 반환한다.

#### **문법**

```sql
CONCAT(arg1, arg2)
```

| DBMS       | 문자열 연결 방법                 |
| ---------- | ------------------------- |
| Oracle     | `CONCAT(a, b)` 또는 `a \|\| b` |
| SQL Server | `a + b` 또는 `CONCAT(a, b)`  |

> Oracle의 `CONCAT`은 **인자를 2개만** 받는다. 3개 이상을 연결하려면 `||`를 쓰거나 중첩해야 한다.

#### **예제**

```sql
SELECT CONCAT('SQL', 'D') AS RESULT1,
       'SQL' || 'D'       AS RESULT2
FROM DUAL;
```

#### **해설**

1. 두 결과 모두 `'SQLD'`를 반환한다.

---

### **2.12 참고: LPAD / RPAD / INSTR (Oracle)**

| 함수                | 설명                           | 예시                       |
| ----------------- | ---------------------------- | ------------------------ |
| LPAD(문자열, 길이, 채움문자) | 왼쪽을 채워 지정한 길이로 만든다.          | `LPAD('7', 3, '0')` → `007` |
| RPAD(문자열, 길이, 채움문자) | 오른쪽을 채워 지정한 길이로 만든다.         | `RPAD('A', 3, '*')` → `A**` |
| INSTR(문자열, 찾을문자)   | 문자가 처음 나오는 위치를 반환한다(없으면 0).  | `INSTR('GOOD MORNING', 'O')` → `2` |

## **3. 숫자 함수(Numeric Function)**

숫자 함수는 숫자형 데이터를 대상으로 다양한 연산을 수행하는 함수이다.

---

### **3.1 ABS**

절댓값을 반환한다.

#### **문법**

```sql
ABS(arg)
```

* **arg** : 숫자형 값 또는 숫자형 칼럼

#### **예제**

```sql
SELECT ABS(-2.3)
FROM DUAL;
```

#### **해설**

1. `-2.3`의 절댓값인 `2.3`을 반환한다.

---

### **3.2 MOD**

첫 번째 인자를 두 번째 인자로 나눈 나머지를 반환한다.

#### **문법**

```sql
MOD(arg1, arg2)
```

* **arg1** : 숫자형 값 또는 숫자형 칼럼
* **arg2** : 숫자형 값 또는 숫자형 칼럼

> SQL Server에서는 `MOD()` 함수 대신 `%` 연산자를 사용한다.

#### **예제**

```sql
SELECT MOD(9, 2)
FROM DUAL;
```

#### **해설**

1. `9 ÷ 2`의 나머지인 `1`을 반환한다.

---

### **3.3 ROUND**

수를 반올림하여 반환한다.

#### **문법**

```sql
ROUND(arg1 [, arg2])
```

| 인자   | 설명                 |
| ---- | ------------------ |
| arg1 | 대상 숫자              |
| arg2 | 소수점 이하 자릿수(생략 시 0) |

> `arg2`가 **음수**이면 소수점 왼쪽(정수부) 자리에서 반올림한다. 예: `ROUND(1234.56, -2)` → `1200`

> 음수는 0에서 먼 방향으로 반올림된다. 예: `ROUND(-2.5)` → `-3`

#### **예제 ①**

```sql
SELECT ROUND(2.67, 1)
FROM DUAL;
```

#### **해설**

1. 소수 둘째 자리에서 반올림하여 `2.7`을 반환한다.

---

#### **예제 ②**

```sql
SELECT ROUND(2.67)
FROM DUAL;
```

#### **해설**

1. 정수로 반올림하여 `3`을 반환한다.

---

### **3.4 TRUNC**

수를 반올림하지 않고 지정한 자릿수까지 남기고 나머지를 버림하여 반환한다.

#### **문법**

```sql
TRUNC(arg1 [, arg2])
```

| 인자   | 설명                     |
| ---- | ---------------------- |
| arg1 | 대상이 되는 숫자형 값 또는 숫자형 칼럼 |
| arg2 | 소수점 이하 자릿수(생략 시 0)     |

> `arg2`가 음수이면 정수부 자리에서 버림한다. 예: `TRUNC(1234.56, -2)` → `1200`

> SQL Server에는 `TRUNC` 함수가 없으며, `ROUND(값, 자릿수, 1)`처럼 세 번째 인자에 0이 아닌 값을 주면 버림으로 동작한다.

#### **예제 ①**

```sql
SELECT TRUNC(2.37, 1)
FROM DUAL;
```

#### **해설**

1. `2.37`을 소수점 첫째 자리까지만 남기고 버림하여 `2.3`을 반환한다.

---

#### **예제 ②**

```sql
SELECT TRUNC(2.37)
FROM DUAL;
```

#### **해설**

1. `2.37`을 정수까지만 남기고 버림하여 `2`를 반환한다.

---

### **3.5 SIGN**

입력된 값이 양수이면 `1`, 음수이면 `-1`, 0이면 `0`을 반환한다.

#### **문법**

```sql
SIGN(arg)
```

* **arg** : 숫자형 값 또는 숫자형 칼럼

#### **예제**

```sql
SELECT SIGN(2.3)
FROM DUAL;
```

#### **해설**

1. `2.3`은 양수이므로 `1`을 반환한다.

---

### **3.6 CEIL**

입력된 값보다 크거나 같은 최소의 정수를 반환한다.

#### **문법**

```sql
CEIL(arg)
```

* **arg** : 숫자형 값 또는 숫자형 칼럼

> SQL Server에서는 `CEIL` 대신 `CEILING`을 사용한다.

#### **예제**

```sql
SELECT CEIL(2.3), CEIL(-2.3)
FROM DUAL;
```

#### **해설**

1. `2.3` 이상인 최소 정수 `3`을 반환한다.
2. `-2.3` 이상인 최소 정수 `-2`를 반환한다.

---

### **3.7 FLOOR**

입력된 값보다 작거나 같은 최대의 정수를 반환한다.

#### **문법**

```sql
FLOOR(arg)
```

* **arg** : 숫자형 값 또는 숫자형 칼럼

#### **예제**

```sql
SELECT FLOOR(2.3), FLOOR(-2.3)
FROM DUAL;
```

#### **해설**

1. `2.3` 이하인 최대 정수 `2`를 반환한다.
2. `-2.3` 이하인 최대 정수 `-3`을 반환한다.

> **음수 주의:** `FLOOR(-2.3)`은 `-3`이고 `TRUNC(-2.3)`은 `-2`이다. (FLOOR는 항상 작은 쪽, TRUNC는 소수부만 버림)

---

### **3.8 기타 숫자 함수**

다음과 같은 숫자 함수도 자주 사용된다.

| 함수    | 설명           |
| ----- | ------------ |
| EXP   | 지수 계산        |
| LOG   | 로그 계산        |
| LN    | 자연로그 계산      |
| POWER | 거듭제곱 계산      |
| SQRT  | 제곱근 계산       |
| SIN   | 사인(Sine)     |
| COS   | 코사인(Cosine)  |
| TAN   | 탄젠트(Tangent) |

## **4. 날짜 함수(Date Function)**

날짜 함수는 날짜(Date) 데이터를 처리하는 함수이다.

---

### **4.1 SYSDATE**

현재 날짜와 시간을 반환한다.

#### **문법**

```sql
SYSDATE
```

> SQL Server에서는 `SYSDATE` 대신 `GETDATE()`를 사용하며, 반드시 괄호를 포함해야 한다.

#### **예제**

```sql
SELECT SYSDATE AS TODAY
FROM DUAL;
```

---

### **4.2 EXTRACT**

날짜 데이터에서 연도, 월, 일 등의 값을 추출한다.

#### **문법**

```sql
EXTRACT(항목 FROM 날짜)
```

| 항목     | 설명 |
| ------ | -- |
| YEAR   | 연도 |
| MONTH  | 월  |
| DAY    | 일  |
| HOUR   | 시  |
| MINUTE | 분  |
| SECOND | 초  |

> SQL Server에서는 `EXTRACT` 대신 `DATEPART()` 함수를 사용한다. (`YEAR()`, `MONTH()`, `DAY()` 함수도 있다.)

#### **예제**

```sql
SELECT
    SYSDATE AS TODAY,
    EXTRACT(MONTH FROM SYSDATE) AS MON,
    EXTRACT(DAY FROM SYSDATE) AS DAY
FROM DUAL;
```

#### **해설**

1. 현재 날짜를 조회한다.
2. 현재 날짜에서 월(MONTH)을 추출한다.
3. 현재 날짜에서 일(DAY)을 추출한다.

---

### **4.3 날짜 연산**

| 연산                     | 설명                       |
| ---------------------- | ------------------------ |
| `SYSDATE + 1`          | 하루 뒤 (Oracle은 날짜에 숫자를 더하면 **일** 단위) |
| `SYSDATE - 1`          | 하루 전                     |
| `날짜1 - 날짜2`             | 두 날짜 사이의 **일수**          |
| `ADD_MONTHS(날짜, n)`    | n개월 뒤 날짜 (Oracle)        |
| `DATEADD(DAY, 1, 날짜)`  | 하루 뒤 (SQL Server)        |
| `DATEDIFF(DAY, 날짜1, 날짜2)` | 두 날짜 사이의 일수 (SQL Server) |

---

## **5. 변환 함수(Conversion Function)**

변환 함수는 데이터 타입을 다른 타입으로 변환하는 함수이다.

형변환은 **암시적 형변환**과 **명시적 형변환**으로 구분된다.

| 구분      | 설명                     |
| ------- | ---------------------- |
| 암시적 형변환 | DBMS가 내부적으로 자동 변환한다.   |
| 명시적 형변환 | 사용자가 함수를 이용하여 직접 변환한다. |

> 암시적 형변환은 성능 저하나 오류가 발생할 수 있으므로 명시적 형변환을 사용하는 것이 좋다.

> 숫자형 칼럼과 문자열을 비교하면 문자열이 숫자로 암시적 변환된다. (변환할 수 없는 문자열이면 에러)

---

### **5.1 TO_NUMBER**

문자열을 숫자형으로 변환한다.

#### **문법**

```sql
TO_NUMBER(arg)
```

* **arg** : 문자열 값 또는 문자열형 칼럼

#### **예제**

```sql
SELECT TO_NUMBER('1001') AS MEMBER_ID
FROM DUAL;
```

#### **해설**

1. 문자열 `'1001'`을 숫자 `1001`로 변환한다.

---

### **5.2 TO_CHAR**

숫자형 또는 날짜형 데이터를 문자열로 변환한다.

#### **문법**

```sql
TO_CHAR(arg1 [, arg2])
```

| 인자   | 설명                    |
| ---- | --------------------- |
| arg1 | 숫자형 또는 날짜형 데이터        |
| arg2 | 날짜 포맷 또는 숫자 포맷(생략 가능) |

#### **예제 ①**

```sql
SELECT TO_CHAR(1001) AS MEMBER_ID
FROM DUAL;
```

#### **해설**

1. 숫자 `1001`을 문자열 `'1001'`로 변환한다.

#### **예제 ②**

```sql
SELECT TO_CHAR(SYSDATE, 'YYYYMMDD') AS TODAY
FROM DUAL;
```

#### **해설**

1. 현재 날짜를 `YYYYMMDD` 형식의 문자열로 변환한다.

#### **날짜 포맷 예**

| 포맷                      | 설명             |
| ----------------------- | -------------- |
| `YYYY`, `MM`, `DD`      | 연, 월, 일        |
| `HH24`, `MI`, `SS`      | 24시간제 시, 분, 초  |
| `YYYY-MM-DD HH24:MI:SS` | 날짜와 시간을 함께 표시  |

#### **숫자 포맷 예**

| 포맷  | 설명                         |
| --- | -------------------------- |
| `9` | 숫자 한 자리 (앞자리가 없으면 공백)      |
| `0` | 숫자 한 자리 (앞자리가 없으면 0으로 채움)  |
| `,` | 천 단위 구분자                   |
| `.` | 소수점                        |

```sql
SELECT TO_CHAR(1234.5, '9,999.99') AS NUM_FMT
FROM DUAL;
```

---

### **5.3 TO_DATE**

문자열을 날짜형으로 변환한다.

#### **문법**

```sql
TO_DATE(arg1, arg2)
```

| 인자   | 설명    |
| ---- | ----- |
| arg1 | 문자열   |
| arg2 | 날짜 형식 |

#### **예제**

```sql
SELECT TO_DATE('20240130', 'YYYYMMDD') AS TODAY
FROM DUAL;
```

#### **해설**

1. `'20240130'` 문자열을 `YYYYMMDD` 형식으로 해석하여 2024년 1월 30일 날짜형으로 변환한다.

---

### **5.4 CAST / CONVERT**

| 함수                                | 설명                                          |
| --------------------------------- | ------------------------------------------- |
| `CAST(값 AS 데이터타입)`                | ANSI 표준 형변환 함수. 대부분의 DBMS에서 사용 가능          |
| `CONVERT(데이터타입, 값 [, 스타일])`        | SQL Server의 형변환 함수. 날짜 포맷 스타일 지정 가능         |

```sql
SELECT CAST('1001' AS NUMBER) FROM DUAL;   -- Oracle
SELECT CAST('1001' AS INT);                -- SQL Server
```

---

## **6. NULL 관련 함수**

NULL 관련 함수는 NULL 값을 다른 값으로 변경하거나 NULL 여부를 판단할 때 사용한다.

---

### **6.1 NVL**

첫 번째 인자가 NULL이 아니면 첫 번째 인자를 반환하고, NULL이면 두 번째 인자를 반환한다.

> 첫 번째 인자와 두 번째 인자의 데이터 타입은 동일해야 한다.

#### **문법**

```sql
NVL(arg1, arg2)
```

* **arg1** : 칼럼 또는 표현식
* **arg2** : NULL일 경우 반환할 값

> SQL Server에서는 `NVL` 대신 `ISNULL` 함수를 사용한다.

#### **예제**

```sql
SELECT EMPNO, ENAME, NVL(COMM, 0) AS COMM
FROM EMP;
```

#### **해설**

1. COMM 칼럼이 NULL이면 `0`으로 변경하여 조회한다.

---

### **6.2 NULLIF**

두 인자의 값이 같으면 NULL을 반환하고, 다르면 첫 번째 인자를 반환한다.

#### **문법**

```sql
NULLIF(arg1, arg2)
```

* **arg1** : 칼럼 또는 표현식
* **arg2** : 비교할 값(동일한 데이터 타입)

#### **예제**

```sql
SELECT EMPNO, ENAME, MGR,
       NULLIF(MGR, 7698) AS NM
FROM EMP;
```

#### **해설**

1. MGR 값이 `7698`이면 NULL을 반환한다.
2. 그렇지 않으면 원래 MGR 값을 반환한다.

---

### **6.3 COALESCE**

입력된 인자를 순서대로 검사하여 **NULL이 아닌 첫 번째 값을 반환**한다.

#### **문법**

```sql
COALESCE(arg1 [, arg2 ...])
```

* **arg1, arg2 ...** : 칼럼 또는 표현식
* 모든 인자는 같은 데이터 타입이어야 한다.
* 모든 인자가 NULL이면 NULL을 반환한다.

#### **예제**

```sql
SELECT EMPNO,
       COALESCE(HOURLY_WAGE, SALARY, COMMISSION) AS TOTAL_SALARY
FROM WAGES;
```

#### **해설**

1. `HOURLY_WAGE`부터 차례대로 검사한다.
2. NULL이 아니면 해당 값을 반환한다.
3. NULL이면 다음 인자를 계속 검사한다.

---

### **6.4 NVL2 (Oracle)**

첫 번째 인자가 **NULL이 아니면 두 번째 인자**를, **NULL이면 세 번째 인자**를 반환한다.

#### **문법**

```sql
NVL2(arg1, arg2, arg3)
```

#### **예제**

```sql
SELECT ENAME, SAL, COMM,
       NVL2(COMM, SAL + COMM, SAL) AS TOTAL
FROM EMP;
```

#### **해설**

1. COMM이 NULL이 아니면 `SAL + COMM`을 반환한다.
2. COMM이 NULL이면 `SAL`만 반환한다.

---

### **6.5 NULL 관련 함수 비교**

| 함수       | 동작                                | 인자 수 |
| -------- | --------------------------------- | ---- |
| NVL      | arg1이 NULL이면 arg2, 아니면 arg1       | 2개   |
| NVL2     | arg1이 NOT NULL이면 arg2, NULL이면 arg3 | 3개   |
| NULLIF   | 두 값이 같으면 NULL, 다르면 arg1           | 2개   |
| COALESCE | NULL이 아닌 첫 번째 값                   | 여러 개 |

> NULL이 포함된 산술 연산(`NULL + 1`)의 결과는 항상 NULL이므로, 계산 전에 NVL 등으로 처리해야 한다.

---

## **7. CASE**

CASE문은 조건에 따라 서로 다른 값을 반환하는 표현식이다.

---

### **형식 ① : 조건식 사용**

```sql
CASE
    WHEN 칼럼1 = 값1 THEN 값A
    WHEN 칼럼1 = 값2 THEN 값B
    ...
    ELSE 값N
END
```

---

### **형식 ② : 비교 대상 지정**

```sql
CASE 칼럼1
    WHEN 값1 THEN 값A
    WHEN 값2 THEN 값B
    ...
    ELSE 값N
END
```

---

### **CASE 동작 규칙**

* WHEN 절을 **위에서부터 순서대로** 검사하고, **처음으로 참이 되는 WHEN**의 결과만 반환한다.
* 어떤 WHEN도 만족하지 않고 **ELSE를 생략**하면 **NULL**을 반환한다.
* 형식 ②는 `=` 비교만 가능하다. NULL 비교는 `CASE 칼럼 WHEN NULL`로 할 수 없고, 형식 ①의 `WHEN 칼럼 IS NULL`을 사용해야 한다.
* THEN 뒤 결과값들의 데이터 타입은 서로 같아야 한다.

---

### **예제**

```sql
SELECT ENAME,
       CASE
           WHEN SAL >= 3000 THEN 'HIGH'
           WHEN SAL >= 2000 THEN 'MIDDLE'
           ELSE 'LOW'
       END AS GRADE
FROM EMP;
```

#### **해설**

1. 급여가 3000 이상이면 `HIGH`를 반환한다.
2. 급여가 2000 이상이면 `MIDDLE`을 반환한다. (3000 이상은 이미 첫 번째 WHEN에서 처리됨)
3. 그 외에는 `LOW`를 반환한다.

---

### **DECODE (Oracle)**

Oracle에서는 `CASE`와 비슷한 기능을 하는 `DECODE` 함수를 제공한다.

#### **문법**

```sql
DECODE(칼럼1, 값1, 결과1 [, 값2, 결과2 ...] [, 기본값])
```

* 칼럼1이 값1과 **같으면** 결과1, 값2와 같으면 결과2를 반환한다.
* 어느 것과도 같지 않으면 **기본값**을 반환하고, 기본값을 생략하면 **NULL**을 반환한다.

#### **예제**

```sql
SELECT ENAME,
       DECODE(DEPTNO, 10, 'ACCOUNTING',
                      20, 'RESEARCH',
                          'OTHER') AS DNAME
FROM EMP;
```

#### **해설**

1. DEPTNO가 10이면 `ACCOUNTING`, 20이면 `RESEARCH`를 반환한다.
2. 그 외에는 `OTHER`를 반환한다.

---

### **CASE와 DECODE의 차이**

| 구분         | CASE                          | DECODE                      |
| ---------- | ----------------------------- | --------------------------- |
| 표준 여부      | ANSI 표준, 모든 DBMS에서 사용 가능      | Oracle 전용 함수                |
| 비교 방식      | 등호 비교와 **범위/복합 조건**(>, <, AND, OR) 모두 가능 | **등호(=) 비교만** 가능            |
| NULL 비교    | `WHEN 칼럼 IS NULL`로 비교 (형식 ②의 `WHEN NULL`은 불가) | NULL과 NULL을 **같은 값으로 취급**하여 비교 가능 |
| 기본값 생략 시   | ELSE 생략 시 NULL                | 기본값 생략 시 NULL                |

```sql
-- DECODE: COMM이 NULL이면 0 (NVL(COMM, 0)과 같은 결과)
SELECT DECODE(COMM, NULL, 0, COMM) FROM EMP;

-- CASE: NULL 비교는 IS NULL을 사용
SELECT CASE WHEN COMM IS NULL THEN 0 ELSE COMM END FROM EMP;
```
