## **4.8 정규표현식**

정규표현식(Regular Expression)은 **문자열의 특정 패턴을 검색, 비교, 치환**하기 위해 사용하는 표현식이다.

SQL에서는 문자열 검색이나 데이터 검증 등에 활용되며, Oracle은 정규표현식 전용 함수를 제공한다.

---

### **1. 정규표현식 메타 문자**

메타 문자(Meta Character)는 **문자 자체의 의미가 아니라 특별한 기능을 수행하는 문자**를 의미한다.

예를 들어 `^`는 문자 `^` 자체를 의미하는 것이 아니라 **문자열의 시작**을 의미한다.

|메타 문자|의미|예|
|---|---|---|
|`\`|메타 문자를 일반 문자로 사용하거나 특수 문자를 표현|`\\` : `\`<br>`\n` : 줄바꿈 문자|
|`^`|문자열의 시작|`^The` : The로 시작하는 문자열|
|`$`|문자열의 끝|`ing$` : ing로 끝나는 문자열|
|`.`|임의의 한 문자(개행 제외)|`a.b` : acb, a-b, a1b|
|`?`|앞 문자가 0개 또는 1개|`no?` : n, no|
|`*`|앞 문자가 0개 이상|`no*` : n, no, noo, nooo|
|`+`|앞 문자가 1개 이상|`no+` : no, noo, nooo|

|메타 문자|의미|예|
|---|---|---|
|`\|`|OR(선택)|`a\|b` : a 또는 b|
|`[]`|대괄호 안 문자 중 하나와 일치|`[abc]` : a, b, c|
|`[-]`|문자 범위 지정|`[a-z]` : a~z 소문자|
|`[^]`|대괄호 안 문자를 제외한 문자|`[^abc]` : a, b, c를 제외한 문자|
|`()`|표현식을 하나의 그룹으로 묶음|`(ab)` : ab|

---

### **2. Oracle 정규표현식 함수**

Oracle은 정규표현식을 활용할 수 있는 다양한 함수를 제공한다.

|함수|설명|
|---|---|
|`REGEXP_LIKE`|정규표현식을 이용한 LIKE 검색|
|`REGEXP_REPLACE`|정규표현식을 이용하여 문자열 치환|
|`REGEXP_INSTR`|정규표현식과 일치하는 문자열의 위치 반환|
|`REGEXP_SUBSTR`|정규표현식과 일치하는 부분 문자열 반환|
|`REGEXP_COUNT`|정규표현식과 일치하는 문자열의 개수 반환|

#### **예제**

```sql
SELECT ENAME
FROM EMP
WHERE REGEXP_LIKE(ENAME, '^S');
````

* `ENAME`이 **S로 시작하는** 사원을 조회한다.

#### **해설**

1. `EMP` 테이블에서 사원명을 조회한다.
2. `REGEXP_LIKE`를 이용하여 `ENAME`이 `S`로 시작하는지 검사한다.
3. 조건을 만족하는 사원만 출력한다.

---

### **3. SQL Server 패턴 문자열**

SQL Server는 Oracle의 정규표현식 함수 대신 `LIKE`와 패턴 문자를 이용하여 문자열을 검색한다.

| 메타 문자 | 의미                | 예                          |
| ----- | ----------------- | -------------------------- |
| `%`   | 0개 이상의 문자         | `%a%` : a를 포함하는 문자열        |
| `_`   | 임의의 한 문자          | `a_b` : acb, a-b, a1b      |
| `[]`  | 대괄호 안 문자 중 하나와 일치 | `[abc]` : a, b, c          |
| `[-]` | 문자 범위 지정          | `[a-z]` : a~z 소문자          |
| `[^]` | 대괄호 안 문자를 제외한 문자  | `[^a-z]` : 소문자 알파벳을 제외한 문자 |

#### **예제**

```sql
SELECT ENAME
FROM EMP
WHERE ENAME LIKE 'S%';
```

* `ENAME`이 **S로 시작하는** 사원을 조회한다.

#### **해설**

1. `EMP` 테이블에서 사원명을 조회한다.
2. `LIKE 'S%'`를 사용하여 `S`로 시작하는 문자열을 검색한다.
3. 조건을 만족하는 사원만 출력한다.
