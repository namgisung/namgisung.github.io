## **지역변수와 전역변수**

### **(1) 지역변수**

함수 안에서 선언된 변수. 그 함수 안에서만 사용 가능하다.

* 함수 안에서 쓰는 변수는 **다른 함수의 변수명과 같아도 됨**
* 서로 다른 함수의 지역변수는 이름이 같아도 **완전히 별개의 저장 공간**

```c
int sum(int x, int y) {
    int temp; // sum 함수의 지역변수
    temp = x + y;
    return temp;
}

int diff(int x, int y) {
    int temp; // diff 함수의 지역변수 (위 sum의 temp와 다름)
    temp = x - y;
    return temp;
}

### 지역변수와 전역변수 비교

| 구분    | 지역변수       | 전역변수    |
| ----- | ---------- | ------- |
| 선언 위치 | 함수 / 블록 내부 | 함수 밖    |
| 사용 범위 | 선언된 영역 내부  | 모든 함수   |
| 생명 주기 | 함수 실행 중    | 프로그램 전체 |
| 사용 목적 | 임시 계산      | 데이터 공유  |
