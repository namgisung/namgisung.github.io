## **함수의 정의**

### **(1) 함수란**

**함수**: 특정 기능을 수행하는 **코드 단위**

**라이브러리 함수**: C에서 기본으로 제공하는 함수 (일종의 "함수 백과사전")

| 헤더 | 기능 |
| --- | --- |
| `stdio.h` | 입출력 |
| `string.h` | 문자열 처리 |
| `math.h` | 수학 연산 |
| `stdlib.h` | 유틸리티 |

---

### **(2) 함수 정의**

**함수 정의**가 되어 있어야 **함수 호출**을 할 수 있다.

**함수 원형(함수 규격)**은 세 가지로 구성된다.

1. 함수명
2. 매개변수
3. 반환형

```c
int sum(int x, int y)     // sum 함수 정의 시작
{
    int temp;              // 두 정수의 합을 잠시 저장할 변수

    temp = x + y;          // x와 y의 합을 temp에 보관

    return temp;           // temp의 값을 반환
}
```

* 함수 몸통은 반드시 **중괄호(`{}`)로 묶어야 함**
* 변수는 가급적 **덜 사용**하는 것이 좋다
* 함수 안에서 쓰는 변수는 **다른 함수의 변수명과 같아도 됨** (서로 영향 없음)

---

### **(3) 재귀 호출**

함수가 **자기 자신을 호출**하는 것.

* **무한 반복을 막기 위한 종료 조건이 반드시 있어야 함**
* 반복문으로 짤 코드를 재귀로 표현하면 **코드가 간단해져서** 사용함
