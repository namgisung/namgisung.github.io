## **매개변수**

### **(1) 인수 / 매개변수**

* **인수(argument)** = 함수 호출 시 전달하는 값
* **매개변수(parameter)** = 함수 정의부에서 값을 받는 변수

```c
sum(a * 2, b / 3);
```

* 매개변수 자리에 **수식**을 사용하면, 그 **수식의 결괏값**이 인수로 전달됨
* 함수 호출 시 전달된 값은 매개변수에 **복사**되어 사용됨 (원본 변수는 영향 없음)
* 인수와 매개변수의 **이름은 달라도 상관없음**

---

### **(2) 매개변수가 없는 함수**

```c
int get_num(void);
```

* 인수와 매개변수가 없다는 뜻
* `void`는 생략 가능하지만, **명시적으로 써주는 것이 좋음**
