# 문자열 처리

C언어에서 문자열은 **문자(char)의 배열**로 표현된다.

따라서 문자열을 다루기 위해서는 문자열 전용 함수들이 필요하며,

이 함수들은 `<string.h>` 헤더 파일에 정의되어 있다.

---

## `#include <string.h>`

```c
#include <string.h>
```

`<string.h>`는 **문자열 처리에 필요한 함수들을 모아둔 헤더 파일**이다.

문자열의 길이, 복사, 비교, 분리(split) 등과 같은 작업을 할 때 반드시 필요하다.

---

## <string.h>에 포함된 대표적인 함수들

| 함수         | 설명                |
| ---------- | ----------------- |
| `strlen()` | 문자열 길이 반환         |
| `strcpy()` | 문자열 복사            |
| `strcmp()` | 문자열 비교            |
| `strcat()` | 문자열 연결            |
| `strtok()` | 문자열 분리 (split 역할) |

---

## 문자열 분리 (split)

자바에는 `String.split()` 메소드가 존재하지만,
**C언어에는 split 전용 함수가 존재하지 않는다.**

대신 `<string.h>`에 포함된 `strtok()` 함수를 이용해 문자열을 분리한다.

---

### strtok() 함수

```c
char *strtok(char *str, const char *delim);
```

* `str` : 분리할 문자열 (첫 호출에서만 전달)
* `delim` : 구분자
* 반환값 : 분리된 문자열의 시작 주소

---

### strtok() 사용 예제

```c
#include <stdio.h>
#include <string.h>

int main() {
    char str[] = "apple,banana,orange";
    char *token;

    token = strtok(str, ",");   // 첫 호출
    while (token != NULL) {
        printf("%s\n", token);
        token = strtok(NULL, ","); // 이후 호출
    }

    return 0;
}
```

#### 실행 결과

```
apple
banana
orange
```

---

### strtok()의 특징

* 구분자를 기준으로 문자열을 나눈다
* **원본 문자열을 변경한다**
* 내부적으로 포인터를 사용한다
* 반복 호출을 통해 다음 토큰을 가져온다

---

## 자바 split()과 C 문자열 처리 비교

| 자바               | C언어           |
| ---------------- | ------------- |
| `String.split()` | `strtok()`    |
| 문자열 객체           | char 배열       |
| 원본 유지            | 원본 변경         |
| 사용 쉬움            | 메모리/포인터 이해 필요 |

---

## 문자열 처리와 포인터의 관계

문자열은 `char` 배열이며,
함수에서 문자열을 다룬다는 것은 **주소(포인터)를 다루는 것**과 같다.

---

## 문자 포인터와 char

알파벳 한 글자는 `char` 자료형 하나로 충분히 표현 가능하기 때문에,

문자를 다룰 때는 **`char` 타입을 사용하는 것이 적합**하다.

---

## 문자열과 널 문자(\0)

### 배열 크기와 널 문자

문자열을 저장할 배열은 **실제 데이터 길이 + 1**만큼의 공간이 있어야 한다.

마지막 칸에는 **널 문자(`\0`)**가 들어가야 하기 때문이다.

```c
char str[6] = "hello"; // h,e,l,l,o,\0 → 6칸 필요
```

* 배열을 `{}`로 초기화할 때는 **컴파일러가 자동으로 `\0`을 넣어준다**
* 널 문자는 **문자열의 끝을 표시**하는 역할
* 숫자로 표현하면 `\0`은 **0**과 같다
* `printf`에서 **널 문자 자체는 출력되지 않는다**

### 직접 대입할 때 주의

배열을 초기화하지 않은 상태에서 문자를 하나씩 직접 대입한다면,

**반드시 마지막 문자 다음에 널 문자를 직접 대입**해 줘야 한다.

```c
char str[6];
str[0] = 'h';
str[1] = 'i';
str[2] = '\0';  // 직접 넣어야 함
```

### scanf로 배열 입력받기

배열을 `scanf`로 입력받을 때는 **`&`를 붙이지 않는다.**

배열 이름 자체가 이미 시작 주소이기 때문이다.

```c
char str[80];
scanf("%s", str);  // &str (X)
```

`scanf`도 입력받을 때 **자동으로 끝에 널 문자를 넣어준다.**

`scanf("%s%s", a, b);`처럼 여러 단어를 받을 때도, 입력할 때는 **공백이나 엔터로 띄워서** 입력해야 한다. `%s`는 공백에서 입력을 멈추기 때문이다.

## strcpy() 상세

`strcpy()`는 문자열을 복사할 때 **널 문자까지 함께 복사**해 준다.

```c
#include <string.h>

char str1[80] = "cat";
char str2[80];

strcpy(str1, "tiger");   // str1에 "tiger" 복사
strcpy(str2, str1);      // str2에 str1의 문자열 복사
```

### strcpy() 사용 규칙

* **첫 번째 인수**: 복사한 값이 저장될 배열 (반드시 **배열**이어야 함)
* **두 번째 인수**: 복사할 문자열
* 오른쪽 값을 왼쪽에 대입하는 것과 같은 개념
* 첫 번째 인수는 문자열을 모두 담을 수 있을 만큼 **충분히 커야 함**
* 첫 번째 인수 자리에는 **문자열 상수를 사용할 수 없음**

```c
strcpy("lion", "tiger"); // 오류
```

위 코드가 안 되는 이유는 `"lion"`이 **읽기 전용(readonly) 데이터**이기 때문이다.

### 배열에 `=`로 직접 대입이 안 되는 이유

```c
char str[80];
str = "apple";  // 오류
```

`str`은 **배열의 시작 주소를 나타내는 상수**이기 때문에,

`=`로 다른 값을 대입할 수 없다. (그래서 `strcpy()`를 써야 함)

### strcpy() 형식

```c
strcpy(저장될_배열명, 저장할_배열명);
```

---

## strncpy()

복사할 **문자 수를 지정**해서 복사한다.

```c
strncpy(str, "apple-pie", 5);
```

* `str` : 저장될 공간
* `"apple-pie"` : 저장할 값
* `5` : 복사할 문자 수
* 원본이 5글자 이상이면 **5글자만 복사하고 `\0`은 저장하지 않는다**. 그래서 `str[5] = '\0';`을 직접 넣어야 한다

---

## strcat() / strncat()

문자열 뒤에 다른 문자열을 **이어 붙인다.**

```c
char str[80] = "straw";

strcat(str, "berry");      // strawberry
strncat(str, "piece", 3);  // strawberrypie
```

* `strcat(str, "berry")` : `str`에 있던 `\0` 위치부터 덮어쓰며 붙이고 끝에 `\0`을 넣는다
* `strncat(str, "piece", 3)` : `"piece"` 중 **3글자(`pie`)만** 붙이고 `\0`을 넣는다
* 이어 붙일 결과가 들어갈 만큼 `str`이 **충분히 커야 한다**

---

## strlen()

문자열의 길이를 반환한다. 널 문자(`\0`)는 **세지 않는다.**

```c
char str[80] = "apple";
printf("%zu\n", strlen(str));   // 5
printf("%zu\n", sizeof(str));   // 80 (배열 전체 크기)
```

---

## strcmp() / strncmp()

두 문자열을 **아스키 코드 값으로 한 글자씩 비교**한다. 처음으로 다른 글자에서 결과가 결정된다.

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char str1[80] = "pear";
    char str2[80] = "peach";

    printf("사전에 나중에 나오는 과일 이름 : ");
    if (strcmp(str1, str2) > 0)    // str1이 str2보다 크면(사전에 나중에 나오면)
        printf("%s\n", str1);      // str1 출력
    else                           // str1이 str2보다 크지 않으면
        printf("%s\n", str2);      // str2 출력

    return 0;
}
```

| 반환값 | 의미 |
| --- | --- |
| `0` | 두 문자열이 같다 |
| 양수 (보통 1) | `str1`이 `str2`보다 사전에 나중에 나온다 |
| 음수 (보통 -1) | `str1`이 `str2`보다 사전에 먼저 나온다 |

* `strncmp(str1, str2, 3)`은 `strcmp`와 거의 같지만 **앞에서부터 지정한 개수만큼만 비교**한다

## 문자열 입출력 함수 (gets, fgets, puts, fputs)

### gets()

```c
gets(str);
```

* **중간의 공백이나 탭을 포함해 한 줄**을 입력받는다
* 입력 끝의 개행 문자(`\n`)는 버퍼에서 읽어 버리고, 배열에는 **`\0`** 을 저장한다. 그래서 문장 출력이 가능하다
* **문자열에 특화**된 함수이고, `scanf`는 단어나 정수 등 다양한 자료형을 받을 수 있다
* 스페이스, 탭, 엔터만 눌러도 입력으로 받는다. `scanf("%s")`는 공백이 아닌 글자가 입력될 때까지 기다린다
* 입력 길이를 검사하지 않아 **위험**하다. C11에서 삭제된 함수라서 **실무에서는 `fgets()`를 쓴다**

```c
#include <stdio.h>

int main(void)
{
    int age;                  // 나이를 저장할 변수
    char name[20];            // 이름을 저장할 배열

    printf("나이 입력 : ");
    scanf("%d", &age);        // scanf 함수로 나이 입력
    getchar();                // 버퍼에 남은 '\n' 제거 (없으면 gets가 빈 줄을 읽음)

    printf("이름 입력 : ");
    gets(name);               // gets 함수로 이름 입력
    printf("나이 : %d, 이름 : %s\n", age, name);

    return 0;
}
```

### fgets()

```c
fgets(str, sizeof(str), stdin);
```

* `str` : 입력받은 문자열을 저장할 배열
* `sizeof(str)` : 최대로 읽을 크기
* `stdin` : **표준 입력**(키보드)
* `gets()`와 달리 **`\n`도 배열에 포함**하고 끝에 `\0`을 붙여 저장한다
* 이름 앞의 `f`는 **file**이라는 뜻으로, 파일에서도 입력받을 수 있어서 붙는다
* `fgets`, `fputs`처럼 `f`가 붙은 함수도 `stdio.h`가 필요하다

### puts() / fputs()

```c
puts(str);            // 출력 후 자동 줄바꿈
fputs(str, stdout);   // 줄바꿈 없이 출력
```

* `puts`는 **줄바꿈을 하고**, `fputs`는 **줄바꿈을 하지 않는다**
* 둘 다 출력에 실패하면 `EOF`(-1)를 반환한다. 성공했을 때는 0 이상의 값을 반환한다 (교재는 0으로 표기)

> 문자열은 시작과 끝이 정해져 있어야 하며, **널 문자를 빠뜨리면 예상치 못한 이상 동작**이 발생할 수 있다.
