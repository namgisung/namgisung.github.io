## 포인터 선언

포인터를 사용하려면 먼저 **포인터 변수를 선언**해야 한다.

C언어에서 포인터 선언은

**“어떤 타입의 값을 가리킬 것인가”**를 명확히 해줘야 한다.

---

### 기본 형태

```c
자료형 *포인터이름;
```

예시)

```c
int *p;
```

* `int` : 가리킬 대상의 자료형
* `*`   : 이 변수가 **포인터임을 나타냄**
* `p`   : 포인터 변수 이름

`p`는 **int형 변수의 주소만 저장할 수 있는 포인터**이다.

---

### 포인터 선언 + 초기화

포인터는 **선언만 하고 사용하면 위험**하므로

대부분 선언과 동시에 초기화한다.

```c
int a = 10;
int *p = &a;
```

* `&a` : 변수 `a`의 주소
* 포인터 `p`는 `a`를 가리키게 된다.

---

### 선언만 하고 초기화하지 않으면?

```c
int *p;
```

이 상태의 `p`는

❌ **어디를 가리키는지 알 수 없는 주소(쓰레기 값)**를 가진다.

이 상태에서 `*p`를 사용하면 **프로그램이 터질 수 있음**

(세그멘테이션 오류)

✔️ 그래서 포인터는 **선언 후 반드시 초기화**하는 습관이 중요하다.

---

### 포인터 타입이 중요한 이유

```c
int a = 10;
double b = 3.14;

int *p1 = &a;     // 가능
double *p2 = &b; // 가능

int *p3 = &b;    // ❌ 타입 불일치
```

포인터는 **가리키는 대상의 타입을 기준으로 동작**한다.

* `int*` → int 크기만큼 접근
* `double*` → double 크기만큼 접근

타입이 틀리면 **메모리 해석이 완전히 틀어짐**

---

### 여러 개의 포인터 선언 시 주의 

```c
int* p1, p2;
```

이 코드는 이렇게 해석된다.

* `p1` → int 포인터
* `p2` → 일반 int 변수

그래서 **가독성 좋은 방식**은 아래처럼 쓰는 것

```c
int *p1;
int *p2;
```

---

### 선언 표기

아래 두 방식은 같은 의미이다.

```c
int *pa;
int* pa;
```

수업에서는 `int *pa;` 형태를 권장한다.

---

### const 포인터

```c
int a = 10;
const int* pa = &a;

*pa = 10;  // 오류 (pa를 통한 값 변경 불가)
a = 20;    // 가능 (변수 a로 직접 변경은 가능)
```

---

### 포인터 대입의 엄격한 규칙

포인터는 일반 변수와 달리 **대입 연산에 엄격한 기준**이 적용된다.
**저장하는 형태와 읽는 형태가 같아야** 한다.

```c
#include <stdio.h>

int main(void)
{
    int a = 10;             // 변수 선언과 초기화
    int* p = &a;            // 포인터 선언과 동시에 a를 가리키도록 초기화
    double* pd;             // double형 변수를 가리키는 포인터

    pd = p;                 // 자료형이 달라 경고 발생
    printf("%lf\n", *pd);   // pd가 가리키는 변수의 값 출력

    return 0;
}
```

* `a`는 4바이트 `int`인데, `pd`는 8바이트 `double`로 그 주소를 읽는다
* 그래서 `*pd`는 `a`의 4바이트(값 10)에 **바로 옆 4바이트(쓰레기 값)** 를 붙여 하나의 `double`로 해석한다
* 형변환으로 대입해도 **읽는 크기는 포인터 자료형을 따른다**

```c
int* q = (int*)pd;  // int 형태로 읽으려면 int* 포인터로 받아야 한다
```

---

### 주소값을 직접 대입하기

```c
int* p;
p = (int*)100;
```

주소값을 직접 쓸 수는 있지만 **권장하지 않는다.**

* 메모리 100번지~103번지가 **어떤 용도의 영역인지 알 수 없다**
* 프로그램 실행 시 **문제를 일으킬 가능성이 크다**
