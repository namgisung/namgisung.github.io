## 포인터 배열

**포인터 배열**은 **포인터들을 모아놓은 배열**이다.

각 배열 요소의 자료형이 포인터형이므로, **배열명 앞에 별(`*`)을 붙여** 선언한다.

---

### (1) 선언

```c
int *pary[3];   // int 포인터 3개를 요소로 갖는 배열
```

```c
char *pary[5] = { "apple", "banana", "kiwi", "melon", "grape" };
```

* `char *`형 변수 5개를 요소로 갖는 포인터 배열의 선언이다
* 모든 배열 요소가 포인터인 저장 공간이 할당된다
* 포인터 배열도 다른 배열처럼 **요소(포인터)들이 연속해서 위치**한다. (각 포인터가 가리키는 문자열이 연속해 있다는 뜻은 아니다)

---

### (2) 포인터 배열과 2차원 배열 비교

```c
char *pary[5] = { "apple", "banana", "kiwi", "melon", "grape" };    // 포인터 배열
char ary[5][20] = { "apple", "banana", "kiwi", "melon", "grape" };  // 2차원 배열
```

| 구분 | 포인터 배열 | 2차원 배열 |
| --- | --- | --- |
| 저장 공간 | 포인터 5개(8바이트 x 5 = 40바이트) + 문자열이 필요한 만큼 | 20바이트 x 5 = 100바이트 고정 |
| 문자열 수정 | 불가 (문자열 리터럴은 읽기 전용) | 가능 |

* **공간을 줄일 때는 포인터 배열이 좋다.** 문자열 길이가 들쭉날쭉할수록 차이가 커진다

---

### (3) 포인터 연산으로 2차원 배열처럼 사용하기

포인터는 **자신이 가리키는 변수의 형태를 알고 있으므로**, 정수 연산만으로 원하는 위치를 찾아갈 수 있다.
그래서 포인터 배열도 2차원 배열처럼 쓸 수 있다.

```c
int a[3] = { 10, 11, 12 };
int b[3] = { 20, 21, 22 };
int c[3] = { 30, 31, 32 };
int *pary[3] = { a, b, c };

printf("%d\n", pary[2][2]);        // 32
printf("%d\n", *(pary[2] + 2));    // 32 (위와 같은 식)
```

`pary[2][2]`의 값을 찾아가는 과정

1. `pary[2]` : 배열 `c`의 시작 주소 (포인터 하나는 8바이트)
2. `pary[2] + 2` : `int` 2칸(8바이트) 뒤, 즉 `c[2]`의 주소
3. `*(pary[2] + 2)` : 그 주소에 저장된 값 → `32`

즉 `pary[2][2]`는 `*(pary[2] + 2)`와 같은 표현이다.

```c
char *pary[5] = {"dog","elephant","horse","tiger","ion"};

char animal[5][20] = {"dog","elephant","horse","tiger","ion"};
```

**2가지 초기화 방법의 차이점** 
* 포인터 배열의 초기화 - 배열 요소에 문자열의 시작 주소만 저장
*  2차원 char 배열의 초기화 - 배열의 공간에 문자열 자체가 저장
*  2가지 모두 초기화 방법이 같으므로 컴파일러는 선언된 배열에 따라 적절한 초기화를 수행
