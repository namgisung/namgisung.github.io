## 포인터의 정의

**포인터(pointer)** 란

**다른 변수의 ‘값’이 아니라 ‘메모리 주소’를 저장하는 변수**이다.

일반 변수는 데이터를 직접 저장하지만,

포인터는 **데이터가 저장된 위치(주소)**를 저장한다는 점에서 차이가 있다.

---

### 변수와 포인터의 차이

```c
int a = 10;
```

* 변수 `a`는 값 `10`을 직접 저장한다.

```c
int *p = &a;
```

* 포인터 `p`는 변수 `a`의 **주소**를 저장한다.
* 즉, `p`는 `a`를 직접 가리킨다.

**값을 다루는 것이 아니라, 값이 있는 위치를 다룬다**는 것이 포인터의 핵심이다.

---

### 왜 포인터가 필요한가?

포인터를 사용하면 다음과 같은 작업이 가능해진다.

* 함수에서 여러 개의 값을 처리
* 배열과 문자열을 효율적으로 처리
* 메모리를 직접 제어
* 동적 메모리 사용 (`malloc`, `free`)

즉, 포인터는 **C언어가 메모리 구조를 직접 다루기 위해 반드시 필요한 개념**이다.

---

### 변수와 메모리

C 프로그램을 컴파일하고 실행(로딩)하면, 프로그램 안의 변수들은 메모리 어딘가에 **저장 공간을 확보**한다.

* `a`와 `b`가 서로 다른 변수라면 두 변수의 공간도 서로 다르다
* 각 공간을 나타내는 **주소**가 있다
* 주솟값으로 공간에 직접 접근하면 **속도가 빠르다**

| 구분 | 의미 |
| --- | --- |
| 변수 | 값을 저장하는 공간 |
| 주소 | 그 공간의 위치 |
| 포인터 변수 | 그 주소를 저장하는 변수 |

---

### 포인터를 자주 쓰는 곳

포인터는 일반 변수 때문이라기보다 **배열** 때문에 자주 사용된다.

---

### 포인터의 크기

포인터의 크기는 **주소의 크기**이므로, 가리키는 자료형(`char`, `int`, `double`)과 관계없이 모두 같다.

* 64비트 환경에서는 보통 **8바이트**
* CPU(환경)에 따라 다를 수 있다
