## 배열과 포인터

포인터는 일반 변수 때문이라기보다 **배열** 때문에 자주 사용된다.

C언어에서 **배열과 포인터는 거의 같은 개념처럼 동작**한다.

정확히 말하면,

배열 이름은 배열의 첫 번째 요소의 주소이다.

이 한 줄이 전부의 시작이다.

---

### 배열 이름의 정체

```c
int arr[5] = {10, 20, 30, 40, 50};
```

이때

* `arr`  → `&arr[0]` 과 동일
* `arr`  → 배열의 **시작 주소**
* 값이 아니라 **주소**다

```c
printf("%d\n", arr[0]);
printf("%d\n", *arr);
```

출력:

```
10
10
```

✔️ `arr[0] == *arr`

컴파일러는 컴파일 과정에서 **배열명을 첫 번째 배열 요소의 주소로 변경**한다.

* 배열 요소는 **연속된 메모리에 일정한 간격(자료형 크기)** 으로 저장된다
* 배열의 이름은 **주솟값**이다

---

### 배열 접근 방식 비교

```c
arr[i]
*(arr + i)
```

두 개는 **완전히 같은 의미**

예시:

```c
printf("%d\n", arr[2]);
printf("%d\n", *(arr + 2));
```

출력:

```
30
30
```

---

### 왜 arr + 1 이 가능한가?

```c
arr + 1
```

이건 “주소 + 1바이트”가 아니다 ✕
**자료형 크기만큼 이동**한다.

```c
int arr[5];
```

* `arr + 1` → 다음 int 요소
* 실제 이동량 → `sizeof(int)` 바이트

포인터 연산은 **타입 기준**이다 (개중요)

---

### 포인터로 배열 다루기

```c
int arr[3] = {1, 2, 3};
int *p = arr;
```

이제 완전히 같은 동작:

```c
p[0] == arr[0]
*(p + 1) == arr[1]
```

출력 예:

```c
printf("%d\n", p[2]);   // 3
printf("%d\n", *(p+2)); // 3
```

#### 포인터 연산식

```c
pa[2] = pa[1] + pa[0];
*(pa + 2) = *(pa + 1) + *(pa + 0);   // 위 식과 같은 의미
```

#### 첫 번째 요소에 접근하는 3가지 방법

* **[방법1]** `pa`를 배열명처럼 사용: `pa[0]`
* **[방법2]** `pa[0]`를 그대로 포인터 연산식으로 변경: `*(pa + 0)`
* **[방법3]** `*(pa + 0)`에서 의미 없는 `0`과 괄호를 제거: `*pa`

#### 포인터 증가

```c
int ary[3] = { 10, 20, 30 };
int* pa = ary;
int i;

printf("배열의 값 : ");
for (i = 0; i < 3; i++)
{
    printf("%d ", *pa);   // pa가 가리키는 배열 요소 출력
    pa++;                 // 다음 배열 요소를 가리키도록 pa 값 증가
}
```

* `pa++`는 주소를 **1바이트**가 아니라 **`int` 한 칸(4바이트)** 만큼 증가시킨다
* 반복문이 끝나면 `pa`는 배열 끝 다음을 가리키므로, 처음부터 다시 쓰려면 `pa = ary;`로 되돌려야 한다

#### 포인터의 덧셈과 뺄셈

```c
int ary[5] = { 10, 20, 30, 40, 50 };
int* pa = ary;           // 첫 번째 배열 요소 주소
int* pb = pa + 3;        // 네 번째 배열 요소 주소

printf("pa : %p\n", (void*)pa);
printf("pb : %p\n", (void*)pb);   // pa보다 3칸(12바이트) 뒤

pa++;                             // pa를 다음 배열 요소로 이동
printf("pb - pa : %td\n", pb - pa);   // 2
```

* `pa + 3`은 3바이트가 아니라 **3칸(12바이트)** 뒤로 이동한 것이다
* **포인터 뺄셈의 결과는 바이트 차이가 아니라 칸 수 차이**이다

#### scanf와 포인터

`scanf` 함수는 입력할 배열 요소의 **주소**가 필요하므로, 그 값을 갖고 있는 포인터를 `&` 없이 **그대로** 사용한다.

```c
int ary[3];
int* pa = ary;
int i;

for (i = 0; i < 3; i++)
{
    scanf("%d", pa);   // pa가 이미 주소이므로 & 불필요
    pa++;
}
```

### 배열 이름 vs 포인터 변수 차이 (중요!)

```c
int arr[5];
int *p = arr;
```

공통점:

* 둘 다 주소처럼 사용 가능
* 인덱싱 가능

차이점:

| 항목   | 배열 이름     | 포인터        |
| ---- | --------- | ---------- |
| 값 변경 | ✕ 불가능     | ◯ 가능       |
| 의미   | 고정된 시작 주소 | 주소를 저장한 변수 |

```c
arr = p; // ✕ 에러
p = arr; // ◯ 가능
```

#### sizeof 결과가 다르다

```c
int ary[3] = { 10, 20, 30 };
int* pa = ary;

printf("%zu\n", sizeof(ary));   // 12 (배열 전체 크기)
printf("%zu\n", sizeof(pa));    // 8  (포인터 크기)
```

* **배열 이름을 포인터에 넣는 순간 배열의 속성(전체 크기 정보)은 사라지고 주소만 남는다**

#### 상수와 포인터의 차이

* 배열명은 **상수 주소**라서 값을 바꿀 수 없다
* 포인터 변수는 값을 바꿀 수 있다

```c
ary++;   // 오류 (배열명은 상수)
pa++;    // 가능
```

---

### 함수에서 배열 전달 = 포인터 전달

```c
void print(int *p) {
    printf("%d\n", p[0]);
}

int main() {
    int arr[3] = {10, 20, 30};
    print(arr);
}
```

배열을 넘긴 것 같지만

실제로는 **첫 요소의 주소**가 넘어간다

✔️ 그래서 C 함수에서 배열 크기를 직접 알 수 없다

---

### 배열 크기 못 구하는 이유

```c
void func(int arr[]) {
    sizeof(arr); // 포인터 크기
}
```

함수 안에서 배열은:

```
int arr[] → int *arr
```

으로 바뀐다.

그래서 항상 길이를 같이 넘긴다:

```c
void func(int arr[], int size)
```
