## **입력**

### **(1) 입력을 사용하기 위한 헤더 포함**

C언어에서 표준 입력을 사용하려면 `stdio.h` 헤더를 포함해야 한다.

```c
#include <stdio.h>
```

---

### **(2) 입력을 저장할 변수 선언**

C언어에서 입력은 **변수에 직접 저장되는 것이 아니라, 변수의 주소에 저장**된다.

따라서 입력을 받기 전에 **반드시 변수를 먼저 선언**해야 한다.

```c
int a;
```

---

### **(3) scanf를 이용한 입력**

C언어에서는 `scanf` 함수를 사용하여 입력을 받는다.

```c
scanf("%d", &a);
```

* `%d` → 입력받을 데이터의 **형식 지정자**
* `&a` → 입력된 값을 저장할 **변수 `a`의 메모리 주소**
* `&` → **주소 참조 연산자**

즉, 위 코드는

> “정수 형식의 데이터를 입력받아 변수 `a`가 저장된 메모리 공간에 저장한다”는 의미이다.

---

### **(4) 형식 지정자 (`%`)**

C언어에서는 입력 데이터의 타입이 고정되어 있지 않기 때문에

형식 지정자(`%`)를 사용하여 어떤 타입의 데이터를 입력받을지 명시해야 한다.

형식 지정자(format specifier, 형식문자)

| 데이터 종류 | 자료형 | 크기(Byte) | 입력 변환 문자 |
| --- | --- | --- | --- |
| 정수 | (unsigned) short | 2 | `%hd` (`%hu`) |
| 정수 | (unsigned) int | 4 | `%d` (`%u`) |
| 정수 | (unsigned) long | 4 | `%ld` (`%lu`) |
| 정수 | (unsigned) long long | 8 | `%lld` (`%llu`) |
| 실수 | float | 4 | `%f` |
| 실수 | double | 8 | `%lf` |
| 실수 | long double | 8, 16 | `%Lf` |
| 문자 | char | 1 | `%c` |
| 문자열 | char 배열 | 가변적 | `%s` |

* 괄호 안은 `unsigned` 자료형일 때의 변환 문자이다

```c
double x;
scanf("%lf", &x);
```

**입력과 출력의 차이 (중요)**

* `printf`에서는 `float`가 `double`로 자동 승격되어 `%f`와 `%lf`가 똑같이 동작한다
* `scanf`는 값을 변수 주소에 직접 저장하므로 승격이 없다. `float`는 `%f`, `double`은 `%lf`로 **반드시 구분**해야 한다

---

### **(5) 문자열 입력**

#### 공백 없는 문자열

```c
char str[100];
scanf("%s", str);
```

* 공백 전까지만 입력받음
* 문자열에는 `&`를 붙이지 않는다

---

#### 공백 포함 문자열 (권장)

```c
char str[100];
fgets(str, sizeof(str), stdin);
```

* 공백 포함 가능
* 엔터(`\n`)까지 함께 입력됨

---

### **(6) 입력 후 출력**

```c
int a;
scanf("%d", &a);

printf("%d\n", a);
```

```c
char str[100];
fgets(str, sizeof(str), stdin);
printf("%s", str);
```

---

### **(7) 여러 개의 입력 받기**

```c
int a, b;
scanf("%d %d", &a, &b);

printf("%d %d\n", a, b);
```

#### 입력

```
5 5
```

#### 출력

```
5 5
```

---

### **(8) 화이트스페이스와 문자 입력**

**화이트스페이스(white space)**: 공백(`' '`), 탭(`\t`), 개행(`\n`)처럼 화면에 보이지 않는 문자

```c
scanf("%c", &a);    // 공백, 개행도 하나의 문자로 입력받음
scanf(" %c", &a);   // %c 앞의 공백이 화이트스페이스를 건너뜀 → 글자만 입력받음
```

---

### **(9) getchar()**

문자 **한 글자**를 입력받아 **문자 코드(정수)로 반환**한다.

```c
int ch;
ch = getchar();      // 한 글자 입력
printf("%c\n", ch);
```

`scanf("%c")`와 `getchar()`의 차이 (변수 `a`가 4바이트 `int`일 때)

* `scanf("%c", &a)`: `a`의 **첫 1바이트에만** 저장한다. 나머지 3바이트는 원래 값(쓰레기 값) 그대로 남는다
* `a = getchar()`: `int` 값을 통째로 반환하므로 **4바이트가 모두 채워진다**

`getchar()`를 반복하면 한 줄을 `char` 배열에 입력받을 수 있다.

```c
char str[80];
int ch, i = 0;

while ((ch = getchar()) != '\n' && ch != EOF && i < 79)
{
    str[i++] = ch;
}
str[i] = '\0';   // 문자열 끝 표시
```

---

### **(10) getchar()의 반환형이 int인 이유**

`getchar()`는 문자만 받는 함수인데 반환형이 `int`다. **문자 이외의 값도 반환하기 때문**이다.

* 입력을 끝내려고 Ctrl + Z(Windows) 또는 Ctrl + D(Linux, macOS)를 누르면 **`EOF`(보통 -1)** 를 반환한다
* 키보드 입력만 있다면 아스키 코드 범위(0~127)가 -1과 겹치지 않아 `char`여도 구분된다
* 하지만 입력 경로가 **파일**이고 읽은 값이 255라면, 1바이트 공간에서 255와 -1은 **같은 비트열(모든 비트가 1)** 이라 구분할 수 없다
* 그래서 문자를 반복 입력할 때는 **반환값을 먼저 `int` 변수에 받아 `EOF`와 비교**한 뒤, `EOF`가 아니면 `char` 변수에 옮겨 쓰는 것이 좋다

`EOF`는 **End Of File**의 약자이며, `-1` 대신 이 이름을 쓴다.

---

### **(11) 버퍼를 사용하는 이유**

**버퍼**는 일정 크기의 연속된 저장 공간이다. (크기는 운영체제에 따라 다를 수 있다)

1. **데이터를 안정적으로 입력받을 수 있다**
   * 키보드로 입력한 데이터는 먼저 저수조 역할의 버퍼에 저장된다
   * 프로그램이 다른 일을 하느라 입력을 바로 받지 못해도 **데이터가 사라지지 않는다**
2. **입력 장치와 독립적으로 사용할 수 있다**
   * `scanf`는 키보드와 직접 연결되지 않고, 정해진 형태의 버퍼에서 입력을 받는다
   * 입력 장치가 바뀌어도 함수를 수정하지 않고 쓸 수 있다
   * 버퍼와 입력 장치의 연결은 **운영체제**가 담당한다

키보드로 `20`을 입력하면, 버퍼에는 문자 `'2'`와 `'0'`이 아스키 코드로 저장되고, 그 뒤 `scanf`가 이를 **정수 20으로 바꿔서** 가져온다.

---

### **(12) 버퍼에 남는 개행 문자 처리**

`scanf`로 숫자를 입력하면 엔터(`\n`)가 버퍼에 남는다. 다음 입력에서 이 `\n`을 읽어버리므로 **잘 제거해야 한다.**

```c
#include <stdio.h>

int main(void)
{
    int num, grade;           // 학번과 학점을 저장할 변수

    printf("학번 입력 : ");
    scanf("%d", &num);        // 학번 입력
    getchar();                // 버퍼에 남아 있는 개행 문자 제거
    printf("학점 입력 : ");
    grade = getchar();        // 학점 입력
    printf("학번 : %d, 학점 : %c", num, grade);

    return 0;
}
```

개행 문자를 지우는 방법

```c
getchar();
scanf("%*c");    // %*c : 한 글자를 읽고 버린다
fgetc(stdin);
```

## **주의사항 (중요)**

### scanf 뒤에 fgets를 바로 쓰면 문제가 생길 수 있다

```c
int a;
char str[100];

scanf("%d", &a);
fgets(str, sizeof(str), stdin); // 빈 줄 입력됨
```

#### 이유

* `scanf`는 **개행 문자(`\n`)를 입력 버퍼에 남김**
* `fgets`가 그 `\n`을 바로 읽어버림

---

### 해결 방법

```c
int a;
char str[100];

scanf("%d", &a);
getchar(); // 남아 있는 '\n' 제거
fgets(str, sizeof(str), stdin);
```

## **scanf 심화**

`scanf`는 값을 **복사**해서 변수에 저장한다.

* `f`는 **변환 문자**가 있다는 의미 → `printf`, `scanf` 이름의 유래로 추정

### 보안 주의

* `scanf`는 **보안에 매우 취약**하다
* 입력 크기를 제한하지 않으면 **비정상 동작**으로 이어질 수 있음 (버퍼 오버플로우 등)

### 입력 방식

* 키보드에서 타이핑한 것은 **전부 문자열로 인식**된다
* 변수 앞에는 **`&`(앰퍼샌드)** 를 붙여 주소를 전달한다

```c
int a;
scanf("%d", &a);
```
