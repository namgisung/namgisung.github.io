## **개요**

### **기본 구조**

```c
#include <stdio.h>

int main(void) {
    printf("Hello, C\n");
    return 0;
}
```

---

### **구성 요소**

1. #include → 헤더 포함
2. main → 프로그램 시작점
3. {} → 코드 블록
4. ; → 문장 끝
5. return 0; → 정상 종료

---

### **main 함수의 구조**

C 프로그램은 **main 함수**에서 시작한다.

* **함수의 머리(header)**: 함수 이름은 **고유 식별자**
* **함수의 몸통(body)**: `{ }` 중괄호로 묶는다
* 몸통 마지막에는 보통 `return 0;`

---

### **프로그램 종료 방법**

1. **Return** — 정상 종료
2. **Exit** — 비정상 종료

---

### **주석**

* `/* ~ */` : `/*`과 `*/` 사이의 모든 내용을 주석 처리
* `//` : `//`부터 해당 줄의 끝까지 주석 처리

```c
/* 여러 줄
   주석 */

// 한 줄 주석
```
