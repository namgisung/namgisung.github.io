## **연산자**

### **(1) 용어**

**연산자**: 연산을 수행하는 기호 (`+`, `-`, `*`, `/` 등)

**피연산자**: 연산자의 작업 대상 (변수, 상수, 수식)

```c
x + 3
```

* 연산자: `+`
* 피연산자: `x`, `3`

---

### **(2) 사칙 연산자 (`+ - * /`)**

사칙 연산자는 프로그래밍에서 가장 많이 사용되는 연산자이다.

```c
int a = 10;
int b = 3;

printf("%d\n", a + b); // 덧셈
printf("%d\n", a - b); // 뺄셈
printf("%d\n", a * b); // 곱셈
printf("%d\n", a / b); // 나눗셈
```

* 피연산자가 **정수형일 경우**, 나눗셈 결과도 정수
* **0으로 나누는 것은 불가능** (실행 오류)

```c
10 / 3 = 3
```

---

### **(3) 할당 연산자**

오른쪽 값을 왼쪽 변수에 저장한다.

```c
a = b;
```

복합 할당 연산자도 사용 가능하다.

```c
a += b;
a -= b;
a *= b;
a /= b;
```

---

### **(4) 비교 연산자**

두 값을 비교하여 **참 또는 거짓**을 판단한다.

```c
a < b
a > b
a <= b
a >= b
```

* 조건문(`if`, `while`)에서 주로 사용됨
* 결과값은 **0(false) 또는 1(true)**

---

### **(5) 등가 비교 연산자**

두 값이 같으면 참, 다르면 거짓

```c
a == b
```

두 값이 다르면 참, 같으면 거짓

```c
a != b
```

⚠️ 주의

```c
a = b   // 대입
a == b  // 비교
```

---

### 🔹 C언어에는 `boolean` 타입이 기본으로 없다

* 비교 결과는 `int` 값으로 반환됨
* `true` → 1
* `false` → 0

```c
if (a == b) {
    // 참
}
```
---

### **(6) 논리 연산자**

여러 조건을 **결합**할 때 사용한다.

```c
a && b   // AND: 둘 다 참이어야 참
a || b   // OR: 하나라도 참이면 참
!a       // NOT: 참/거짓 반전
```

**숏 서킷 룰(short circuit rule, 단축 평가)**

**좌항만으로 `&&`와 `||`의 연산 결과를 판별**하는 규칙이다.

* `&&`는 좌항이 거짓이면 우항과 관계없이 결과가 거짓이므로 **우항을 살펴볼 필요가 없다**
* `||`는 좌항이 참이면 우항과 관계없이 결과가 참이므로 **우항을 살펴볼 필요가 없다**

```c
if (a != 0 && 10 / a > 1) {
    // a가 0이면 10/a는 실행되지 않음 → 0으로 나누기 오류 방지
}
```

**주의할 점**

```c
(a < 0) && (++b > 20)
```

* 이런 식에서 **항상 `++b`가 실행되길 기대할 수 없다**
* `a`가 0 이상이면 좌항이 거짓이라서 `b` 값은 **증가되지 않는다**

숏 서킷 룰은 불필요한 연산을 줄여 **실행 속도를 높일 수 있지만**, 증감 연산처럼 우항에 부수 효과가 있으면 **예상치 못한 결과**를 만들 수 있다.

### **(7) 증감 연산자 (전위 / 후위)**

```c
++a  // 전위
a++  // 후위
```

* **전위(`++a`)**: 먼저 **증감시키고** 연산에 사용
* **후위(`a++`)**: 먼저 **연산에 사용하고** 증감

```c
int a = 5;
int b = ++a; // a를 먼저 6으로 만들고 대입 → b = 6
int c = a++; // 먼저 대입(6)하고 a는 7이 됨 → c = 6, a = 7
```

#### 전위 표기와 후위 표기

증감 연산자의 위치를 `a++` 혹은 `a--`와 같이 피연산자 **뒤**로 옮길 수도 있다.

* **전위 표기(prefix)**: 증감 연산자가 피연산자 **앞** (`++a`, `--a`)
  * 값이 **증감하고 나서** 연산에 사용
* **후위 표기(postfix)**: 증감 연산자가 피연산자 **뒤** (`a++`, `a--`)
  * 연산에 **사용하고 나서** 값이 증감

```c
#include <stdio.h>

int main(void)
{
    int a = 5, b = 5;
    int pre, post;

    pre = (++a) * 3;     // 전위형 증감 연산자
    post = (b++) * 3;    // 후위형 증감 연산자

    printf("증감후 a = %d, b = %d\n", a, b);
    printf("전위형: (++a) * 3 = %d, 후위형 : (b++) * 3 = %d\n", pre, post);

    return 0;
}
```

실행 결과

```
초깃값 a = 6, b = 6
전위형: (++a) * 3 = 18, 후위형 : (b++) * 3 = 15
```

* 전위형: `a`가 먼저 6이 된 뒤 `6 * 3 = 18`
* 후위형: `b`가 5인 채로 `5 * 3 = 15`가 계산되고, 그다음에 `b`가 6이 됨
* 두 경우 모두 연산이 끝난 뒤 변수 값은 **6**으로 같고, 차이는 **연산에 쓰이는 값**이다

⚠️ **하나의 수식에서 같은 변수를 두 번 이상 사용할 때는 증감 연산자를 쓰면 안 됨** (동작이 예측 불가능해짐)

### **(8) sizeof 연산자**

변수나 자료형이 차지하는 **바이트 크기**를 반환한다.

```c
printf("%lu\n", sizeof(int)); // 4
```

### **(9) 콤마 연산자**

**콤마 연산자는 대입 연산자보다 우선순위가 낮은 유일한 연산자**다.
따라서 대입 연산자와 함께 사용할 때는 반드시 **괄호가 필요**하다.

```c
res = (++a, ++b);
```

* 괄호가 있으면: `(++a, ++b)` 전체가 하나의 식으로 계산되어 **마지막 값인 증가된 b의 값**이 res에 저장됨

```c
res = ++a, ++b;
```

* 괄호가 없으면 콤마 연산자의 우선순위가 낮으므로 `res = ++a` 가 먼저 수행되고, 그다음 `++b`가 별도로 수행됨
* 즉 `res = ++a; ++b;` 와 동일 → **res에는 증가된 a의 값**, b는 그냥 1 증가

⚠️ 별개의 두 문장을 한 줄에 쓸 거라면 콤마 연산자 대신 **세미콜론(`;`)**을 쓰는 것이 좋음

---

### **(10) 조건 연산자 (`? :`)**

**조건문이 아니라 조건 표현식**이다.

```c
결과 = (조건) ? 참일 때 값 : 거짓일 때 값;
```

```c
int max = (a > b) ? a : b;
```

---

### **(11) 비트 연산자 (`& | ^ ~ << >>`)**

비트 단위로 연산한다. **잘 사용되진 않지만 하드웨어 조작에 쓰인다.**

00000000 00000000 00000000 00001010 // 10을 32비트로 표현


| 연산자 | 의미 |
| --- | --- |
| `&` | AND — 2진수에서 and 연산 |
| `\|` | OR — 2진수에서 or 연산 |
| `^` | XOR — 두 비트가 다르면 1, 같으면 0 |
| `~` | NOT — 비트 반전(마이너스) |
| `<<` | 왼쪽 시프트 (2배) |
| `>>` | 오른쪽 시프트 (1/2배) |

### **(12) 형변환**

#### 자동 형 변환 (암시적 / 묵시적 형 변환)

컴파일 과정에서 **피연산자의 형태가 다르면 형태를 일치시키는 작업**을 수행한다.

**형 변환의 기본 규칙**

* 데이터 크기가 **작은 값이 큰 값으로** 바뀐다
* 예) 정수(4바이트)와 실수(8바이트)를 연산하면 **정수가 실수로** 자동 변환되어 연산된다
* 다만 **대입 연산은 메모리에 값을 저장**하므로 **무조건 좌항의 변수형에 맞게** 저장된다

```c
int a = 10;
double b = a;         // 자동 형변환 (int → double)

double c = 3.5;
int d = c;            // 좌항(int)에 맞게 저장 → 3 (소수점 버림)
```

자동 형 변환은 형태가 다른 데이터를 자유롭게 연산할 수 있도록 도와주지만, **예상치 못한 값의 변형**이 생길 수 있다.
가능하면 **피연산자의 형태를 같게 맞춰** 사용하는 것이 좋다.

#### 수동 형 변환 (명시적, 캐스팅)

큰 자료형 → 작은 자료형 (바이트 손실 가능)

```c
double c = 3.14;
int d = (int)c;        // 수동 형변환 (강제 캐스팅)
```

```c
double r1 = 10 / 3;      // 3.000000 (정수끼리 먼저 나누고, 그 결과를 double로 저장)
double r2 = 10 / 3.0;    // 3.333333 (한쪽이 실수라 실수 연산)
double r3 = (double)10 / 3;  // 3.333333 (캐스팅으로 한쪽을 실수로)
```

* 실수 결과가 필요하면 **연산에 쓰이는 피연산자 중 적어도 하나가 실수**여야 한다
* 변수가 `double`이라는 것만으로는 연산이 실수로 처리되지 않는다
