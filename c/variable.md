## **변수**

### **(1) 기본 구조**

```c
int a;
```

이런 식으로 **정수형 변수 `a`를 선언**한다.

```c
int a = 10;
```

이런 식으로 **변수를 선언함과 동시에 값을 초기화**한다.

---

### **(2) 상수 변수 선언**

C언어에는 **`const`** 를 사용한다.
값이 한 번 정해지면 **변경할 수 없는 변수**다.

```c
const int a = 0;
```

---

### **(3) 강제 형 변환 (형변환, 캐스팅)**

변수 타입을 바꾸고 싶을 때 **강제 형 변환**을 사용한다.

형식:

```
(타입)값
```

```c
double input = 3.14;     // 실수형 변수
int intValue = (int)input; // 실수 → 정수 (소수점 버림)

printf("%d\n", intValue); // 출력: 3
```

C에서 **소수점은 자동으로 버려진다**

---

### **(4) 변수 기본 자료형 종류**

#### 논리형

```c
#include <stdbool.h>

bool isTrue = true;
```

* `stdbool.h` 필요
* `true` / `false`
* 조건문에 사용

---

#### 문자형

```c
char c = 'A';
```

* **한 문자만 저장**
* 반드시 `' '` (작은따옴표) 사용

---

#### 문자열

C에는 `String` 타입이 없음
→ **문자 배열(`char[]`)로 표현**

```c
char str[] = "Hello";
```

* 문자열은 `" "` (큰따옴표)
* 마지막에 `\0`(널 문자) 자동 포함

---

#### 정수형

```c
int num = 10;
```

---

#### 실수형

```c
float f = 3.14f;
double d = 3.14;
```

* `float` → 뒤에 `f` 붙이는 게 정석
* `double` → 기본 실수형

---

### **char vs 문자열 차이**

```c
char c = 'A';        // 문자 1개
char s[] = "A";     // 문자열
```

| 구분 | char   | 문자열      |
| -- | ------ | -------- |
| 저장 | 1글자    | 여러 글자    |
| 표기 | `'A'`  | `"ABC"`  |
| 타입 | `char` | `char[]` |

---

### **(5) 정수의 음수 표현**

* **1의 보수**
* **2의 보수**

---

### **(6) 진법 표기**

* 숫자 앞에 `0` → **8진수**
* 숫자 앞에 `0x` → **16진수**
* 수학에서는 `6_8`, `11_8` 처럼 밑수를 표현

---

### **(7) 실수 저장 방식 (정규화)**

소수점 형태는 컴퓨터에서 보통 **정규화**로 저장된다.
정규화는 **소수점 앞에 1의 자리 숫자**가 있어야 한다.

---

### **(8) 자료형 크기 (바이트 / 비트)**

| 자료형 | 바이트 | 비트 |
| --- | --- | --- |
| 정수(int) | 4 | 32 |
| 실수(double) | 8 | 64 |
| 문자 변수(char) | 1 | 8 |
| 문자 상수('A' 등) | 4 | 32 |

* `char` **변수**는 1바이트(8비트)를 차지한다
* 하지만 `'A'` 같은 **문자 상수(character constant)** 는 C에서 타입이 `int`로 취급되어 **4바이트(32비트)**를 차지한다

---

### **(9) 정수 리터럴에 LL 붙이기**

컴파일러가 자동으로 판단하는 게 아니라, 본인이 직접 수 뒤에 **`LL`**을 붙이면 지정 가능하다.

```c
long long a = 100LL;
```

---

### **ASCII vs 유니코드**

| 구분 | ASCII | 유니코드 |
| --- | --- | --- |
| 대상 | 미국 | 전 세계 |
| 등장 | 1960 | 1970 |
| 표현 개수 | 128 | \infty |

* **encoding**: 문자를 비트/바이트로 변환
* **decoding**: 비트/바이트를 문자로 변환

---

## **(10) l-value / r-value**

* **l-value(left value)**: 저장 공간으로 사용하는 변수
* **r-value(right value)**: 값으로 사용하는 변수
* **l-value에는 숫자가 올 수 없다** (예: `3 = a;` 불가능)

## **(12) 정수형 출력 서식**

* `long` 출력 → `%ld`
* `long long` 출력 → `%lld`

---

## **(13) signed / unsigned**

* **signed**: `-` ~ `+` 부호 있음
* **unsigned**: `0` ~ `+` (부호 없음)

```c
unsigned int a; // 부호 안 씀
```

* `%d` → 음수, 0, 양수 모두 구분해서 출력
* `%u` → **양수로만** 출력 (unsigned 전용)

---

| --- | --- |

| long double | 15 |

## **(15) 문자열 복사**

문자열은 `=`로 바로 복사할 수 없고, **`strcpy()`** 를 사용해야 한다.

```c
strcpy(fruit, "banana"); // fruit에 banana 복사
```
