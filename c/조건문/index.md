## **조건문**

**조건문**은 특정 조건에 따라 실행할 코드를 다르게 선택하는 제어 구조다.

### **종류**

* [if문](if문/if.html) — 조건이 참일 때 실행
* [else](if문/else.html) — 조건이 거짓일 때 실행
* [else if](if문/else-if.html) — 여러 조건을 순서대로 검사
* [switch문](switch.html) — 하나의 값에 따라 여러 실행 경로 중 선택

---

### **중괄호 생략 규칙**

* 조건문에서 **실행문이 한 줄이면 중괄호(`{}`) 생략 가능**
* 단, **실행문이 두 줄 이상이면 반드시 중괄호로 묶어야 함**

```c
if (a > 0)
    printf("양수\n"); // 한 줄이라 중괄호 생략 가능

if (a > 0) {
    printf("양수\n");
    a--;               // 두 줄 이상이면 중괄호 필수
}
```

---

### **분기문의 종류**

조건이나 흐름에 따라 코드의 실행 위치를 바꾸는 문장들이다.

* `continue` — 반복문의 다음 순회로 건너뜀
* `break` — 반복문/switch문을 즉시 빠져나옴
* `goto` — 지정한 라벨로 무조건 이동
* `return` — 함수를 종료하고 값을 반환
