## **if문**

조건식이 **참(0이 아님)** 이면 실행문을 수행하는 조건문이다.

### **기본 구조**

```c
if (조건식) {
    // 조건이 참일 때 실행
}
```

```c
int a = 10;

if (a > 0) {
    printf("a는 양수입니다\n");
}
```

* 조건식의 결과가 **0이면 거짓, 0이 아니면 참**으로 판단
* 실행문이 한 줄이면 중괄호를 생략할 수 있다

```c
if (a > 0)
    printf("양수\n");
```
